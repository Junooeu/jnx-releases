# JNX

Offizielle Downloads für **JNX** - Windows Tweaking-, Cleaning- und Security-Suite.

## Download

Neueste Version: **[JNX-Setup herunterladen](https://github.com/Junooeu/jnx-releases/releases/latest)**

Einmal installieren - danach aktualisiert sich JNX automatisch.

> Beim ersten Start fragt Windows nach Adminrechten (für die System-Tweaks). Da die App noch nicht signiert ist, kann SmartScreen eine Warnung zeigen: *Weitere Informationen -> Trotzdem ausfuehren*.
